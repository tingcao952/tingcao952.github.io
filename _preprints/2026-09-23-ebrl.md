excerpt: 'Embodied reinforcement learning combines environment simulation, action generation, and model updates, whose heterogeneous CPU and GPU demands make efficient resource utilization difficult. EBRL is an asynchronous embodied RL training system that uses an asynchronous pipelined scheduler to overlap rollout and training while eliminating synchronization stalls, together with a fine-grained resource manager that dynamically allocates pooled CPU cores and GPU streaming multiprocessors. Evaluated with four embodied policies and four simulation benchmarks across heterogeneous GPU testbeds, EBRL achieves 1.30–3.47x higher end-to-end rollout throughput and 2.5x faster training convergence than state-of-the-art embodied RL systems.'
