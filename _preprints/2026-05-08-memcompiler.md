excerpt: 'Embodied-agent memory systems commonly inject retrieved memory as static context at episode start, which becomes misaligned as execution state evolves. MemCompiler reframes memory use as State-Conditioned Memory Compilation: a learned compiler reads a structured Brief State and dynamically selects and compiles relevant memory into executable guidance delivered through text and latent Soft-Mem channels. Across ALFWorld, EmbodiedBench, and ScienceWorld, it improves open-source backbones by up to 129%, approaches frontier closed-source systems, and reduces per-step latency by 60%.'
